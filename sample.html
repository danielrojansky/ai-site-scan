Step 1: Add structured data (JSON-LD)

Why: structured data gives AI exact facts, like your name, logo and what you offer, so it does not have to guess. Worth up to 14 points.

Add this to the <head> of the homepage. Replace the TODO values, and remove lines you have no real value for.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Organization",
      "@id": "https://react.dev/#organization",
      "name": "React",
      "url": "https://react.dev/",
      "logo": "https://react.dev/TODO-logo.png",
      "description": "React is the library for web and native user interfaces. ...",
      "sameAs": [
        "https://www.linkedin.com/company/TODO",
        "https://x.com/TODO",
        "https://www.crunchbase.com/organization/TODO"
      ],
      "contactPoint": {
        "@type": "ContactPoint",
        "contactType": "customer support",
        "email": "TODO@react.dev"
      }
    },
    {
      "@type": "WebSite",
      "@id": "https://react.dev/#website",
      "name": "React",
      "url": "https://react.dev/",
      "inLanguage": "en",
      "publisher": { "@id": "https://react.dev/#organization" }
    }
  ]
}
</script>

Check: paste the homepage URL in validator.schema.org and fix any errors.

Step 8: AI agents, make the page usable

Why: browser agents such as ChatGPT agent, Claude in Chrome and Gemini read the page structure and look at the screen. Agent grade now: B.

  • Fail Search works only inside a pop-up. There is no results address an agent can open or come back to.
  • Warn 28 different buttons are all called "Save".
  • Warn 2 main headings, so the topic is unclear.
  • Pass All 31 buttons and 72 links have a name, all 3 form fields have a label, and nothing covers the page when it loads.

Give search a results address:

<form role="search" action="https://react.dev/search" method="get">
  <label for="q">Search</label>
  <input id="q" type="search" name="q">
  <button type="submit">Search</button>
</form>

Make button names unique:

<button aria-label="Save TODO: which item">Save</button>
