What AI gets: HTML before JavaScript, as text

The AI view is a simulation. It shows the server HTML with no JavaScript run, turned into text. This is what most AI crawlers and fetch tools (ChatGPT, Claude, Perplexity) get. Some tools, such as Google, can run JavaScript. The screenshot comes from a real browser that runs JavaScript, like a human visitor. Compare the two views: text that is in the screenshot but not in the AI view is invisible to most AI tools.
